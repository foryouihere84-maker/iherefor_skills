## 5. 变更同步机制

架构层为全局共享，改动会波及其他**批次**。本节规定「改什么、同步什么、卡在哪」。

| 编号 | 变更类型 | 必须同步的内容 | 卡点 |
|---|---|---|---|
| S1 | 共享层模块边界的划分 / 层次关系变更 | 本文件 + 两端代码 + **所有活跃批次**的落地计划 | 交付门 |
| S2 | 契约本身变更（字段 / 枚举 / 口径 / 错误） | **先改 `01-需求` 两份**，再改本文件第 2 节落点 + 两端代码 | 契约先改 |
| S3 | 序列化 / 持久化方案变更 | 本文件第 3 节 + 两端代码 + 迁移方案 + `一致性对账` | |
| S4 | 新增 seam | 本文件第 4 节 + 两端实现 + 测试替身 | |

> 对齐 `references/代码文档同步.md` 的「工程 → 文档」回写要求：改代码必须按映射表回写对应文档章节。

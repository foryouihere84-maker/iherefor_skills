# 阅读应用 — 回滚方式

> 导航入口：`../../00-入口/文档导航.md`。所属阶段：阶段 4 工程落地计划。任务编号：4.3。
> **所属批次：`01-多格式书架与续读`**（= `NN-<需求名>`）。批次目录名在 01/02/04/05/06 各阶段间**必须同名对齐**。
> **产物类型：收敛型（批次内）**。命名 `回滚方案.md`（无序号单例）。
> 表达「**本批次结束时的**当前真相」，随本轮上游产物演进**原地更新**，不另建版本文件。
> **非首批次开工时，应先从上一批次的同名文件继承**，再在本批次内继续演进。

## 1. 回滚路径

| 变更类型 | 回滚/降级路径 |
|---|---|
| 领域实体/共享纯函数（Book/SharedRules） | 纯增量代码，无迁移；回滚=删除新增文件即回到骨架占位，不影响既有占位 |
| BookParser 协议 + 各 Parser 实现 | 增量实现，可整体回退到「无解析能力」状态，不影响编译（仅去掉引用） |
| EPUB 自研最小解析 | 若解析不达标，降级路径=替换为 Readium（协议已预留 seam），业务层不动 |
| PDF 系统渲染 | 无第三方依赖，回滚=移除 PDF 相关 render view，退回无 PDF 阅读 |
| 轻量序列化持久化 | 本期不引入 DB/schema 迁移；回滚=删除序列化文件 + 移除 Repository 读写代码，无数据迁移 |
| 文件导入（fileImporter / SAF） | 无权限模型变更（SAF 无需存储权限），回滚=移除导入入口 |
| 占位 View/Activity 改造 | 回滚=恢复占位 `Text("书架")` 原始版本（脚手架源码可回溯） |

**总体策略**：本功能是绿地增量开发、无既有工程破坏、无 DB/schema 迁移、无第三方依赖，回滚成本极低。核心回滚边界是「共享层契约」——若阶段 6 对账发现文档与代码漂移，优先回写文档对齐代码，而非回退整块代码（除非代码本身是错误的实现）。

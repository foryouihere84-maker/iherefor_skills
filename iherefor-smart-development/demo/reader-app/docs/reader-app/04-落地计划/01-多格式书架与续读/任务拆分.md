## 1. Tickets

### T-1 共享领域模型与不变量（两端）

- 依赖：无
- 范围：定义 `Book`/`ReadingProgress`/`Chapter`/`BookFormat`/`LocatorType` 及 8 条不变量对应的纯函数（格式校验、进度↔格式兼容校验、越界回退、sourceUri 去重）。
- 完成标准：两端各自有同语义实体 + 纯函数；单测覆盖「不支持格式拒绝」「越界回退」「重复去重」「进度格式兼容」四类边界（US-1 不支持格式、US-5 越界、US-1 重复导入）。

### T-2 TXT 解析（两端）

- 依赖：T-1
- 范围：TxtParser 实现章节切分 + 编码探测（UTF-8 优先），输出 ParsedBook（章节序列）。
- 完成标准：两端 TxtParser 通过；测试覆盖空文件、无空行切分、GBK 兜底。

### T-3 EPUB 最小解析（两端）

- 依赖：T-1
- 范围：EpubParser 解 ZIP + 解析 OPF/NCX + 抽章节纯文本，实现 BookParser 协议。
- 完成标准：两端 EpubParser 对合法 EPUB 抽出章节；测试覆盖损坏文件/缺 OPF 的失败路径（错误显式报告）。

### T-4 PDF 系统渲染（两端）

- 依赖：T-1
- 范围：iOS 用 PDFKit、Android 用 PdfRenderer 按页渲染；进度用 pageIndex。
- 完成标准：两端 PDF 阅读界面能打开并翻页；进度定位为页码（不变量「PDF⇒page」）。

### T-5 文件导入 + 格式识别（两端）

- 依赖：T-1
- 范围：iOS fileImporter + UTType；Android SAF ACTION_OPEN_DOCUMENT + 持久授权；格式识别为 BookFormat。
- 完成标准：能选中文件 → 识别格式 → 生成 Book 记录；测试/验证覆盖「不支持格式拒绝」「重复导入去重」。

### T-6 书架 + 持久化 + 删除（两端）

- 依赖：T-1
- 范围：LibraryRepository 实现书架 CRUD、按 importedAt 降序、轻量序列化持久化、删除（仅移除记录与进度）。
- 完成标准：书架列表展示书名/作者/格式/进度；删除后记录与进度一并移除、源文件不动（US-2 浏览、US-5 删除）。

### T-7 阅读器导航 + 进度续读（两端）

- 依赖：T-2/T-3/T-4
- 范围：按格式分派到阅读器；保存/恢复 ReadingProgress。
- 完成标准：EPUB/TXT 进入重排阅读、PDF 进入按页阅读；退出重进恢复到上次位置（US-3 阅读、US-4 续读）。

### T-8 双端编译 + 对账 + 交付（两端）

- 依赖：T-1~T-7
- 范围：双端分别编译 0 error；代码↔文档一致性对账；产出交付报告。
- 完成标准：iOS BUILD SUCCEEDED + Android BUILD SUCCESSFUL；对账无未处理漂移项。

# 阅读应用 — 领域模型

> 导航入口：`../../00-入口/文档导航.md`。所属阶段：阶段 1 需求理清。任务编号：1.3。
> **所属批次：`01-多格式书架与续读`**（= `NN-<需求名>`）。批次目录名在 01/02/04/05/06 各阶段间**必须同名对齐**。
> **产物类型：收敛型（批次内）**。命名 `领域模型.md`（无序号单例）。
> 表达「**本批次结束时的**当前真相」，随本轮上游产物演进**原地更新**，不另建版本文件。
> **非首批次开工时，应先从上一批次的同名文件继承**，再在本批次内继续演进。

> **职责边界（与 `跨端共享需求.md` 的唯一分工口径）**
> 本文件回答「**领域里有什么**」：术语叫什么、实体有哪些字段、字段什么含义与类型、什么条件恒成立、枚举有哪些取值。
> **两档都产出**（含单端开发）；字段的语义与类型定义以本文件为家。
> `跨端共享需求.md` 回答「**两端怎么写才一致**」：双端字面映射、接口调用姿势、跨端口径、错误语义对齐——
> 它承载跨端契约的权威裁定，且只登记跨端维度，**不重抄本文件的语义与类型**。
> 两者按**列**分工，不按**行**重复：同一个字段名会同时出现在两份文件里，但说的不是同一件事。

## 1. 术语表

**一个概念只能有一个名字，一个名字只能指一个概念。**

| 术语 | 权威名（代码名） | 定义 |
|---|---|---|
| 书籍 | `Book` | 导入到书架的一个阅读单元，对应一个文件但抽象为「可阅读的出版物」 |
| 书架 | `Library` | 所有书籍的集合及对集合的管理视图 |
| 导入 | `importBook` | 从系统文件选择器 / 分享入口把外部文件登记为「书籍」的过程 |
| 阅读器 | `Reader` | 打开书籍后的阅读界面，按格式（EPUB/PDF/TXT）选择不同渲染路径 |
| 阅读进度 | `ReadingProgress` | 用户上次读到的位置（EPUB/TXT 为章节 + 偏移，PDF 为页码） |
| 文档格式 | `BookFormat` | 书籍的格式枚举：epub / pdf / txt |
| 定位类型 | `LocatorType` | 进度的定位方式：chapter（章节）/ page（页码） |
| 元数据 | `Metadata` | 从文件中解析出的书名、作者、封面等描述信息 |
| 源文件 | `sourceUri` | 用户在设备上导入时的原始文件定位 |
| 文档流 | `ParsedBook` | 解析后供重排阅读使用的章节序列 |
| 书籍仓库 | `LibraryRepository` | `Book` 集合的读写接口（领域层抽象，实现可替换：首版为内存实现） |

> 「禁止使用的同义词」不在本表——那是跨端命名纪律，见 `跨端共享需求.md` 第 2.2 节。

## 2. 实体

### `Book`（书籍）

| 字段名 | 语义 | 类型口径 | 可选性 | 取值约束 | 默认值 |
|---|---|---|---|---|---|
| `id` | 本地唯一标识 | `标识` | 必填 | 非空；**本端生成**的 UUID 字符串（跨端不保证相等，见跨端档 2.3） | 导入时生成 |
| `title` | 书名 | `字符串` | 必填 | 非空 | 由调用方给出（通常取文件名） |
| `author` | 作者 | `可选<字符串>` | 可空 | — | 空（首版未解析元数据，恒为空） |
| `format` | 书籍格式 | `枚举<BookFormat>` | 必填 | 取值域见第 4 节；**导入后不可变**（V1） | 由源文件扩展名判定 |
| `sourceUri` | 源文件定位 | `字符串` | 必填 | 非空；**全局唯一**（V2）；平台定位形态见跨端档第 9 节 | — |
| `coverUri` | 封面定位 | `可选<字符串>` | 可空 | — | 空（首版未解析，恒为空） |
| `importedAt` | 导入时刻 | `时间点` | 必填 | 绝对时刻；精度与格式口径见跨端档第 6 节 | 导入时刻 |
| `progress` | 当前阅读进度 | `可选<ReadingProgress>` | 可空 | 至多一条（V3） | 空（导入时未读） |

### `ReadingProgress`（阅读进度）

| 字段名 | 语义 | 类型口径 | 可选性 | 取值约束 | 默认值 |
|---|---|---|---|---|---|
| `bookId` | 所属书籍 | `标识` | 必填 | 对应某个 `Book.id` | — |
| `locatorType` | 定位方式 | `枚举<LocatorType>` | 必填 | 取值域见第 4 节；**必须与所属 `Book.format` 兼容**（V4） | — |
| `chapterIndex` | 章节序号 | `可选<整数>` | 可空 | ≥ 0；越界回退到 0（V5）；仅 `chapter` 定位时有效 | 空 |
| `offset` | 章节内偏移 | `可选<整数>` | 可空 | ≥ 0（首版未启用逐字定位，恒为空） | 空 |
| `pageIndex` | PDF 页码 | `可选<整数>` | 可空 | ≥ 0；越界回退到 0（V5）；仅 `page` 定位时有效 | 空 |
| `updatedAt` | 更新时刻 | `时间点` | 必填 | 绝对时刻；口径见跨端档第 6 节 | 当前时刻 |

### `Chapter`（章节，重排格式）

| 字段名 | 语义 | 类型口径 | 可选性 | 取值约束 | 默认值 |
|---|---|---|---|---|---|
| `index` | 章节序号 | `整数` | 必填 | 从 0 起**连续**；与列表位置一致 | — |
| `title` | 章节标题 | `字符串` | 必填 | 可为空串（取该章首行为标题，首行缺失则为空） | 空串 |
| `content` | 章节正文 | `字符串` | 必填 | 非空 | — |

### `ParsedBook`（文档流）

| 字段名 | 语义 | 类型口径 | 可选性 | 取值约束 | 默认值 |
|---|---|---|---|---|---|
| `chapters` | 章节序列 | `列表<Chapter>` | 必填 | **至少 1 项**（空则视为解析失败）；**有序**，按 `index` 升序 | — |

**类型口径词表**（与 `跨端共享需求.md` 共用，只用这几种）：

| 口径 | 含义 | 本批次使用处 |
|---|---|---|
| `字符串` | 文本 | `title` / `author` / `sourceUri` / `coverUri` / `Chapter.title` / `Chapter.content` |
| `整数` | 无小数 | `chapterIndex` / `offset` / `pageIndex` / `Chapter.index` |
| `时间点` | 绝对时刻 | `importedAt` / `updatedAt` |
| `枚举` | 取值域有限 | `BookFormat` / `LocatorType` |
| `列表<…>` | 有序集合 | `ParsedBook.chapters` |
| `可选<…>` | 可能不存在 | 见各表「可选性」列为「可空」的字段 |
| `标识` | 唯一标识 | `Book.id` / `ReadingProgress.bookId` |

> 本批次不涉及 `布尔` / `浮点` / `时长` / `字节串` 口径。

**「可选性」三态**：

| 取值 | 含义 | 本批次字段 |
|---|---|---|
| 必填 | 一定存在；缺失即为非法数据 | `Book` 的 `id` / `title` / `format` / `sourceUri` / `importedAt`；`ReadingProgress` 的 `bookId` / `locatorType` / `updatedAt`；`Chapter` 全部；`ParsedBook.chapters` |
| 可空 | 存在但语义为「无」 | `author` / `coverUri` / `progress` / `chapterIndex` / `offset` / `pageIndex` |
| 有默认值 | 缺省时取默认值 | 本批次无（Kotlin 侧 `= null` / `= System.currentTimeMillis()` 是语言层默认，语义上分别等同「可空」与「必填 + 生成时赋值」） |

> **未使用哨兵值**：`author` / `coverUri` / `progress` 均用可选表达「无」，未用空串或 `-1` 冒充。

**实体关系**：

| 关系 | 基数 | 说明 |
|---|---|---|
| `Book` ↔ `ReadingProgress` | **一对一（至多一条）** | 每个 `Book` 至多持有一条当前进度（V3）；进度不独立于书籍存在 |
| `Library` → `Book` | 一对多 | 书架是全部 `Book` 的集合视图，按 `importedAt` 降序呈现（V7） |
| `ParsedBook` → `Chapter` | 一对多 | `ParsedBook` 是 `Chapter` 的有序容器；`ParsedBook` 不持久化，仅解析期内存活 |

## 3. 不变量

| 编号 | 不变量 | 违反时的行为 |
|---|---|---|
| V1 | `Book.format` 只能是 epub / pdf / txt 三者之一，且**导入后不可变** | 导入时拒绝（返回「不支持的格式」，见跨端档 7.1 E1）；已导入书籍改格式一律视为非法操作 |
| V2 | 同一源文件（`sourceUri`）重复导入**只产生一条**书籍记录 | 拒绝新增，返回「已存在」（见跨端档 7.1 E2） |
| V3 | `ReadingProgress` 与 `Book` **一对一**（每个 Book 至多一条当前进度） | 覆盖旧记录，不新增第二条 |
| V4 | `locatorType` 必须与 `format` 兼容：`pdf` ↔ `page`、`epub`/`txt` ↔ `chapter`；且只用对应的定位字段（PDF 用 `pageIndex`，EPUB/TXT 用 `chapterIndex` + `offset`） | 拒绝写入（静默忽略本次进度保存，见跨端档 7.1 E7） |
| V5 | 进度序号必须落在实际范围内：`chapterIndex` < 章节总数、`pageIndex` < 页数；**越界（含负数）一律回退到起点 0** | 回退到 0（第一章 / 第一页），不抛错、不保留越界值 |
| V6 | 删除书籍时不得出现悬挂状态：记录与源文件的处置必须二选一（仅移记录 / 连带源文件），且 `progress` 一并移除 | 拒绝该删除方式；不允许出现「记录已删但源文件仍不可达」被静默接受 |
| V7 | 书架返回顺序恒为 `importedAt` **降序**（最新导入在前） | 排序保证；实现须显式排序，不得依赖存储实现顺序 |

> 编号 `V1`~`V7` 由本文件唯一持有；`跨端共享需求.md` 引用这些编号，不重抄条文。

## 4. 枚举与取值域

| 枚举名 | 取值 | 含义 | 用于哪些字段 |
|---|---|---|---|
| `BookFormat` | `epub` | 电子出版物（EPUB，重排格式） | `Book.format` |
| | `pdf` | 便携文档格式（按页渲染，非重排） | `Book.format` |
| | `txt` | 纯文本（按空行切分章节，重排格式） | `Book.format` |
| `LocatorType` | `chapter` | 按章节定位（适用于 `epub` / `txt`） | `ReadingProgress.locatorType` |
| | `page` | 按页码定位（适用于 `pdf`） | `ReadingProgress.locatorType` |

> 本表只承载**取值语义**（这个取值是什么意思）。
> 跨端相关内容——**线格式名、双端代码字面、未知值处理、冻结 / 可增长**——见 `跨端共享需求.md` 第 5 节。
> 单端开发时只产出本文件，故取值本身必须在此定义完整。

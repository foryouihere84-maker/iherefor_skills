## 1. 用户故事

### US-1 导入书籍

作为读者，我想要从设备导入 EPUB/PDF/TXT 文件，以便把它们加入我的书架。

优先级：P0

### US-2 浏览书架

作为读者，我想要看到一个统一的书架列表（书名、作者、格式、进度），以便快速找到并选择要读的书。

优先级：P0

### US-3 打开并阅读

作为读者，我想要打开一本书进入适合其格式的阅读界面，以便阅读内容。

优先级：P0

### US-4 阅读进度续读

作为读者，我想要应用记住我读到的位置，以便下次打开时自动续读。

优先级：P0

### US-5 删除书籍

作为读者，我想要从书架删除不再需要的书，以便保持书架整洁。

优先级：P1

## 2. 验收场景

### US-1 场景（导入书籍）

- Given 用户在书架界面，设备上有 EPUB/PDF/TXT 之一
- When 用户发起导入并选择一个支持格式的文件
- Then 应用解析格式与元数据，生成一条书籍记录并出现在书架中

### US-1 场景（导入不支持格式）

- Given 用户选择一个不支持格式的文件（如 .mobi）
- When 应用尝试导入
- Then 应用拒绝导入并提示「不支持的格式」，不产生书籍记录

### US-1 场景（重复导入）

- Given 书架已存在书籍 A（同一 sourceUri）
- When 用户再次导入同一文件
- Then 应用不产生重复记录，而是提示已存在或静默去重

### US-2 场景（浏览书架）

- Given 书架有若干书籍
- When 用户打开书架
- Then 列表按导入时间降序展示书名、作者、格式与进度

### US-3 场景（按格式阅读）

- Given 书架中有一本 EPUB/TXT 书
- When 用户点击打开
- Then 进入重排文本阅读界面，可翻页/滚动
- Given 书架中有一本 PDF 书
- When 用户点击打开
- Then 进入按页渲染的阅读界面，可翻页

### US-4 场景（续读）

- Given 用户读到某书第 N 章（或 PDF 第 P 页）后退出
- When 用户再次打开该书
- Then 应用恢复到上次位置（而非回到开头）

### US-5 场景（删除书籍）

- Given 书架有一本书
- When 用户执行删除并确认
- Then 该书籍记录从书架移除，且进度一并移除

### US-5 场景（越界进度回退）

- Given 书籍的章节数/页数因重新导入发生变化导致进度越界
- When 用户打开该书
- Then 应用回退到起点（第一章/第一页），不崩溃

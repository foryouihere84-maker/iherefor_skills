## 1. 问题清单

- iOS 端解析 EPUB 的官方/成熟推荐方案是什么（是否用 Readium Swift Toolkit，还是自研解析）？
- Android 端解析 EPUB 的官方/成熟推荐方案是什么（Readium Kotlin Toolkit 的角色）？
- PDF 阅读在 iOS / Android 两端各自的官方推荐渲染方案是什么（是否用系统内置 PDFKit / PdfRenderer，无需第三方依赖）？
- TXT 纯文本如何切分章节、在两端如何重排渲染，官方推荐做法是什么？
- iOS 端如何通过系统 API 导入文件并识别格式（fileImporter + UTType）？
- Android 端如何通过 SAF（ACTION_OPEN_DOCUMENT）导入文件并持久访问 content URI？
- 跨端契约（领域语义 + 跨端共享约束）在「两端语言不同」下如何做到语义一致？架构层如何设计落点，使漂移在编译期或对账期可被发现？
- 本地持久化（书架 + 进度）在两端各自的官方推荐方案是什么（是否用 Room / SwiftData / Core Data）？

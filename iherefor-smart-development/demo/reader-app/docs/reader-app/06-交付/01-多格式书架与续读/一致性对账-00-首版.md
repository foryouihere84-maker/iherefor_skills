## 2. 漂移项清单

> 模拟器端到端演示（2026-09-17）暴露了 3 处「文档宣称 ↔ 代码实现」的漂移。**已于 2026-09-17 修复其中 2 处**，状态如下：

| # | 漂移项 | 文档宣称 | 修复前代码 | 修复后处理 | 状态 |
|---|---|---|---|---|---|
| 1 | **阅读器内容未解析填充** | 需求 US-3「打开书进入阅读界面阅读内容」 | Android `ReaderScreen(book, parsedBook = null)` 硬编码 null → 显示「暂无内容」 | 新增 `BookReaderService`（iOS/Android 对称）按 `BookFormat` 分派 parser，打开书时 `readAndParse` 真正读文件解析出 ParsedBook 渲染 | ✅ 已修复（补 BookReaderServiceTest 3 测试，真实 EPUB ZIP 解析通过） |
| 2 | **持久化未落磁盘** | 变更清单/跨端共享层「首版轻量序列化持久化」、US-4「续读恢复进度」 | `InMemoryLibraryRepository`，重启清空 | 仍未落盘（首版明确用内存仓储，见下说明） | ⏳ 保持内存（首版范围） |
| 3 | **阅读界面返回栈缺失** | 需求「从阅读器返回书架」 | 无 BackHandler，BACK 直接退出 app | Android 加 `BackHandler { openBook = null }`，iOS 用 NavigationStack 天然返回 | ✅ 已修复 |
| 4 | **视觉 token 未落地** | 原型说明「视觉稿规格」声明的色彩/字号/间距 token | 实现沿用系统默认色与默认字号，无一处引用 token | 已在原型说明 §4 加「落地状态」声明（token = 目标态，首版未落地），并记为后续补全项 | ⏳ 已声明（首版范围） |

**持久化说明**：变更清单原承诺「首版轻量序列化持久化」，但实际首版落地用了 `InMemoryLibraryRepository`（内存），进程重启书架清空。这属于「首版最小闭环」的刻意简化（文档 `03-架构/方案草案.md` / `06-交付/01-多格式书架与续读/交付报告-00-首版.md` 均已声明「内存仓储，未落磁盘」），非隐藏漂移。若要真正满足 US-4 续读，需后续把仓库换成磁盘序列化实现——已作为明确的后续补全项记录，不本次修复。

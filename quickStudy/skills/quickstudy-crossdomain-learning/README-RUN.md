# quickStudy Skill 运行入口说明

## 1. 目标

运行跨领域速学 Skill，满足：

- 先判意图（了解知识 / 解决问题）
- 了解知识分支输出首屏固定 6 段
- 深挖双入口（编号 + 自然语言）
- 争议显式标注不确定性
- 支持导出知识结果 + 全量问答过程

## 2. 前置条件

- 可加载 [SKILL.md](./SKILL.md) 的宿主环境
- 模板目录可读：`templates/`
- 导出目录可写：`exports/`

## 3. 启动入口

### 3.1 Skill 文件路径

- `quickStudy/skills/quickstudy-crossdomain-learning/SKILL.md`

### 3.2 宿主命令占位

```bash
<your-skill-runner> --skill quickStudy/skills/quickstudy-crossdomain-learning/SKILL.md
```

说明：仓库当前无统一 skill loader 代码；上面命令按你实际运行器替换。

## 4. 触发门控（核心）

收到用户输入后，先判意图：

- 了解知识：触发知识流（澄清 -> 6 段 -> 深挖 -> 导出）
- 解决问题：不触发 6 段，走问题求解流（目标 -> 约束 -> 可执行步骤 -> 风险回滚）
- 意图不明确：先问 1 个意图澄清问题

## 5. 交互入口

### 5.1 首轮输入示例

- 知识理解：`零信任架构`
- 问题求解：`Redis 一直超时，怎么处理？`
- 输入不足：`数学`

### 5.2 深挖入口

- 编号：`1`~`5`
- 自然语言：例如 `给我反例场景`

## 6. 导出入口

触发词：

- `导出`
- `export`
- `保存学习记录`

输出路径：

- 默认 Markdown：`exports/YYYY-MM-DD-<topic>-study.md`
- 可选 JSON：`exports/YYYY-MM-DD-<topic>-study.json`

导出内容必须包含：

1. 知识结果（首屏 + 深挖 + 修订轨迹）
2. 全量交互过程（用户问题 + 模型回应，时间顺序）

## 7. 冒烟验证（最小）

1. 输入 `零信任架构`：应输出完整 6 段
2. 输入 `2`：应进入“详细案例拆解”
3. 输入 `Redis 一直超时，怎么处理？`：应走问题求解流，不输出 6 段
4. 输入争议主题：应出现“不确定/常见争议”标注
5. 输入 `导出`：导出文件应包含知识结果 + 全量问答

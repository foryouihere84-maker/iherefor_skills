# 发布前验收清单（严格门槛映射）

## 发布类型判定（先选）

- 规范包发布（仅本仓库文档资产）：必须通过“仓库内静态一致性检查”，运行时门槛可标记为“需宿主 runner 复核”。
- 运行时发布（接入宿主 runner）：必须同时通过“运行时门槛”与“仓库内静态一致性检查”。

## 运行时门槛（需宿主 runner，必须 100%）

- [ ] **检查项**：自由输入解析通过（问题/关键词/短句）  
      **检查方法**：宿主 runner 执行样例集（需宿主 runner）  
      **通过条件**：全部样例正确分支
      **证据**：运行日志 + 结果报告

- [ ] **检查项**：知识分支首屏 6 段齐全  
      **检查方法**：宿主 runner 抽样检查（需宿主 runner）  
      **通过条件**：抽样命中率 100%
      **证据**：抽样记录

- [ ] **检查项**：深挖双入口可连续多轮（编号 + 自然语言）  
      **检查方法**：宿主 runner 连续会话脚本（需宿主 runner）  
      **通过条件**：编号与自然语言均可路由
      **证据**：会话 transcript

- [ ] **检查项**：输入不足时先澄清且预算不超限  
      **检查方法**：宿主 runner 用例（需宿主 runner）  
      **通过条件**：首次实质回答前澄清问题 <= 1
      **证据**：会话 transcript

- [ ] **检查项**：导出完整（知识结果 + 学习过程摘要表）  
      **检查方法**：导出文件核对（需宿主 runner）  
      **通过条件**：字段完整率 100%
      **证据**：导出样本 + 字段核对表

## 质量门槛（严格）

- [ ] **检查项**：2 分钟复述可通过  
      **检查方法**：抽样主题复述测试（需宿主 runner）  
      **通过条件**：成功率 >= 90%
      **证据**：评分记录

- [ ] **检查项**：回顾题有效（每主题 5 题，检索 3 + 迁移 2）  
      **检查方法**：抽样题集审阅（需宿主 runner）  
      **通过条件**：结构符合率 100%，正确率 >= 80%
      **证据**：题目与评分表

- [ ] **检查项**：深挖无纯复读  
      **检查方法**：人工审阅 + 重复率检查（需宿主 runner）  
      **通过条件**：无“仅复述”样本
      **证据**：审阅结论

- [ ] **检查项**：争议主题 100% 标注不确定性  
      **检查方法**：争议主题样本检查（需宿主 runner）  
      **通过条件**：全部包含不确定/争议显式标注
      **证据**：样本清单

- [ ] **检查项**：结论修订可追踪（更新结论 + 原因）  
      **检查方法**：修订场景样本检查（需宿主 runner）  
      **通过条件**：修订样本 100% 带原因
      **证据**：修订日志

## 稳定性门槛

- [ ] **检查项**：黄金样例集 >= 50 条并全量回归  
      **检查方法**：宿主 runner 回归执行（需宿主 runner）  
      **通过条件**：回归通过率 100%
      **证据**：回归报告

- [ ] **检查项**：P0/P1 问题为 0  
      **检查方法**：缺陷列表审计  
      **通过条件**：发布前无未关闭 P0/P1
      **证据**：缺陷看板快照

- [ ] **检查项**：抽检 20 份导出文件字段完整率 100%  
      **检查方法**：导出抽检（需宿主 runner）  
      **通过条件**：20/20 通过
      **证据**：抽检记录

## 仓库内静态一致性检查（本仓库可执行）

- [ ] **检查项**：`SKILL.md` 包含 `clarificationBudget` 规则  
      **检查方法**：`grep -n "clarificationBudget" quickStudy/skills/quickstudy-crossdomain-learning/SKILL.md`  
      **通过条件**：命中 >= 1
      **证据**：命令输出

- [ ] **检查项**：`SKILL.md` 明确分支收口差异（问题求解分支无 1~5 菜单）  
      **检查方法**：`grep -n "禁止输出知识深挖菜单" quickStudy/skills/quickstudy-crossdomain-learning/SKILL.md`  
      **通过条件**：命中 >= 1
      **证据**：命令输出

- [ ] **检查项**：模板与主规范均包含 `topicSlug`  
      **检查方法**：`grep -n "topicSlug" quickStudy/skills/quickstudy-crossdomain-learning/SKILL.md quickStudy/skills/quickstudy-crossdomain-learning/templates/export-*.md`  
      **通过条件**：全部命中
      **证据**：命令输出

- [ ] **检查项**：导出触发规则为命令式  
      **检查方法**：`grep -n "命令式" quickStudy/skills/quickstudy-crossdomain-learning/SKILL.md quickStudy/skills/quickstudy-crossdomain-learning/README-RUN.md`  
      **通过条件**：全部命中
      **证据**：命令输出

## 拦截条件（任一命中即不发布）

- [ ] 知识分支漏任一核心段
- [ ] 导出摘要表缺关键字段或关键阶段
- [ ] 争议主题未标注不确定性
- [ ] 深挖明显复读且无新增
- [ ] 问题求解分支错误出现 1~5 知识菜单
- [ ] 发现导出路径未使用 `topicSlug`

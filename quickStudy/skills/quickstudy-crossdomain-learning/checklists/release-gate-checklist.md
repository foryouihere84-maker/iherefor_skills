# 发布前验收清单（严格门槛映射）

## 功能门槛（必须 100%）
- [ ] 自由输入解析通过（问题/关键词/短句）
- [ ] 首屏 6 段齐全（允许轻微重排，不可缺段）
- [ ] 深挖双入口可连续多轮（编号 + 自然语言）
- [ ] 输入不足时先澄清（仅 1 个问题）
- [ ] 导出完整（知识结果 + 全量问答过程）

## 质量门槛（严格）
- [ ] 2 分钟复述可通过（抽样主题成功率 >= 90%）
- [ ] 回顾题有效（每主题 5 题，检索+迁移）
- [ ] 深挖无纯复读
- [ ] 争议主题 100% 标注不确定性
- [ ] 结论修订可追踪（更新结论 + 原因）

## 稳定性门槛
- [ ] 黄金样例集 >= 50 条并全量回归
- [ ] P0/P1 问题为 0
- [ ] 抽检 20 份导出文件，字段完整率 100%

## 拦截条件（任一命中即不发布）
- [ ] 漏任一核心段
- [ ] 导出缺任一对话轮次
- [ ] 争议主题未标注不确定性
- [ ] 深挖明显复读且无新增

# 质量门槛自检清单（每轮输出前）

## A. 阶段约束
- [ ] 首轮已先做意图分类（了解知识 / 解决问题）
- [ ] 输入不足时，只问了 1 个澄清问题
- [ ] 知识分支首屏阶段已完整覆盖 6 段（无缺段）
- [ ] 知识分支深挖阶段内容为增量（无纯复读）
- [ ] 导出阶段包含知识结果 + 全量交互

## B. 真实性与不确定性
- [ ] 争议点已显式标注“不确定/常见争议”
- [ ] 没有把争议观点写成唯一事实

## C. 一致性
- [ ] 若结论被新信息修正，已写“更新结论 + 原因”
- [ ] 与前文无自相矛盾表述

## D. 可回顾性
- [ ] 关键概念可在 2 分钟内复述
- [ ] 若输出回顾题，包含检索题与迁移题

## E. 导出完整性（触发导出时）
- [ ] 首屏 6 段已写入导出
- [ ] 深挖内容已写入导出
- [ ] 修订轨迹已写入导出（若有）
- [ ] 用户/模型每轮对话按时间顺序完整写入

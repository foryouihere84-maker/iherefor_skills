# 质量门槛自检清单（每轮输出前）

## A. 阶段约束

- [ ] **检查项**：首轮已先做意图分类（了解知识 / 解决问题）  
      **检查方法**：查看本轮输出是否出现明确意图判定结论  
      **通过条件**：存在且仅存在一个意图分支

- [ ] **检查项**：澄清预算遵守 `clarificationBudget = 1`  
      **检查方法**：回看会话，统计首次实质回答前澄清问题次数  
      **通过条件**：<= 1；超限即失败

- [ ] **检查项**：知识分支首屏 6 段完整  
      **检查方法**：对照 6 段标题逐项核对  
      **通过条件**：6 段齐全，无缺段

- [ ] **检查项**：知识分支深挖为增量  
      **检查方法**：对比首屏与深挖内容，检查是否仅复述  
      **通过条件**：每轮深挖至少新增 1 个实质信息点

- [ ] **检查项**：问题求解分支尾部不含知识菜单  
      **检查方法**：检查尾部是否出现 `1~5` 菜单  
      **通过条件**：未出现菜单，仅执行反馈提示 + 导出提示

- [ ] **检查项**：导出触发必须命令式  
      **检查方法**：判断触发输入是否为命令式（导出/export/保存学习记录，可带格式参数）  
      **通过条件**：语义提及不触发

## B. 真实性与不确定性

- [ ] **检查项**：争议点已显式标注“不确定/常见争议”  
      **检查方法**：检索争议段是否包含明确标注词  
      **通过条件**：争议主题 100% 标注

- [ ] **检查项**：未把争议观点写成唯一事实  
      **检查方法**：检查争议段措辞是否单断言无前提  
      **通过条件**：包含适用前提或分歧说明

## C. 一致性

- [ ] **检查项**：结论修订时已写“更新结论 + 原因”  
      **检查方法**：若存在修订，检索固定句式  
      **通过条件**：修订轮次全部带原因

- [ ] **检查项**：与前文无自相矛盾  
      **检查方法**：核对当前结论与上一结论冲突点  
      **通过条件**：冲突项已修订并解释

## D. 可回顾性

- [ ] **检查项**：关键概念可 2 分钟复述  
      **检查方法**：人工抽查“记忆锚点 + 3 个关键点”  
      **通过条件**：可独立复述

- [ ] **检查项**：回顾题结构正确（若输出）  
      **检查方法**：统计题型分布  
      **通过条件**：检索题 3 + 迁移题 2

## E. 导出完整性（触发导出时）

- [ ] **检查项**：首屏 6 段已写入导出（未进入知识分支时给出原因）  
      **检查方法**：检查导出“知识结果”块  
      **通过条件**：存在且语义完整

- [ ] **检查项**：深挖内容已写入导出（无则固定“无”/`[]`）  
      **检查方法**：检查深挖字段  
      **通过条件**：有值或符合空值约定

- [ ] **检查项**：修订轨迹已写入导出（无则固定“无”/`[]`）  
      **检查方法**：检查修订字段  
      **通过条件**：有值或符合空值约定

- [ ] **检查项**：学习过程摘要表完整写入（非全量对话）  
      **检查方法**：检查表格是否包含关键阶段、时间顺序、增量信息字段  
      **通过条件**：关键阶段不缺失；摘要行时间递增；每行包含新增/修订点

- [ ] **检查项**：文件名使用 `topicSlug`  
      **检查方法**：检查导出路径是否为 `YYYY-MM-DD-HHMMSS-<topicSlug>-study.*`  
      **通过条件**：不出现原始非法字符主题
